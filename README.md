# Selah Studio - Portifólio de Fotografia
**Selah Studio** é um portfólio web desenvolvido para apresentar um estilo de fotografia.<br>
Ok, vamos ser sinceros: o site ficou **lindo no computador**, mas...

**A Responsividade deu B.O.**:<br>
Eu foquei tanto na estética para telas grandes (desktop) que, quando você abre no celular, o layout dá aquela "quebrada" básica. Ele não está *tão* amigável e responsivo quanto eu queria.

* **[Bora ver o Selah Studio online!](https://hadjars.github.io/site-fotografy/)**
